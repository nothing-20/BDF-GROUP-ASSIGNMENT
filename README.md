# FitNest Gym – Locker Management System
## Backend Development Fundamentals (Modules 1, 2, 3) – Group Assignment

Welcome to the **FitNest Gym – Locker Management System** repository.

The entire project and its source files are organized inside the **[`group-assignment`](./group-assignment/)** directory:

- 📁 **[`group-assignment/`](./group-assignment/)**
  - 📁 `config/` – Database configuration & initialization
  - 📁 `database/` – Relational schema DDL (`schema.sql`)
  - 📁 `routes/` – Express router endpoints (`members`, `lockers`, `allotments`)
  - 📁 `controllers/` – Controllers & business logic
  - 📁 `middleware/` – Validation middleware
  - 📁 `screenshots/` – Screenshot documentation & project evidence folders
  - 📁 `tests/` – Automated API test suites
  - 📄 `server.js` – Main Express server application
  - 📄 `package.json` – Dependencies & scripts
  - 📄 `postman_collection.json` – API testing collection
  - 📄 `README.md` – Full documentation, API reference, & Viva Voce guide

---

### Quick Start

```bash
# Navigate to the group-assignment directory
cd group-assignment

# Install dependencies
npm install

# Start the server
npm start

# Run automated tests
npm test
```

For full details, please refer to the main **[group-assignment/README.md](./group-assignment/README.md)**.
